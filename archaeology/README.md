# Archaeology Engine Deliverables

Generated by GLM Commit Archaeology Engine.

## Included Deliverables in this Folder
- `CORRECT.md` - Success ledger with all confirmed clean commits (newest first)
- `WRONG.md` - Failure and recovery ledger with paired fix commits (newest first)
- `stuff.md` - GLM intelligence deep archaeological report
- `COMMITS_LEDGER.md` - Complete per-commit breakdown and unified diffs
- `RAW_GIT_LOG.txt` - Complete extracted git history
- `SUMMARY.json` - Machine-readable stats summary
